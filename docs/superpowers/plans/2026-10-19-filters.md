# Filters — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Saved filters (name + query) using a Todoist-style query language, listed in the sidebar, each opening a view of matching open tasks.

**Architecture:** `core::filter` = tokenizer + recursive-descent parser → AST → evaluator against a `FilterContext` (today, project/section names). Pure and host-tested. Filters persist in the existing `filter` table via `FilterAdd/Update/Delete`. The service evaluates a filter over open tasks (comma = separate result groups) and validates queries. The UI adds a Filters sidebar section with an add/edit form that validates live, and a filter view.

**Spec:** `docs/superpowers/specs/2026-10-19-todoist-tauri-port-design.md` (§6 filter-query v1 subset)

## Query language (v1)
- Operators: `&` (and, binds tighter), `|` (or), `!` (not), parentheses, `,` (separate groups, shown as separate lists).
- Terms (case-insensitive): `all`, `today`, `tomorrow`, `overdue`, `no date`, `recurring`, `no labels`, `subtask`, `p1`–`p4`, `#Project` (also `##Project`), `/Section`, `@label`, `search: text`, `due before: D`, `due after: D`, `due: D`, `N days` / `next N days` (today ≤ due < today+N).
- Dates `D`: `today`, `tomorrow`, `yesterday`, `+N days`, `-N days`, `YYYY-MM-DD`.
- Invalid queries return a clear error (unknown term, unbalanced parentheses, dangling operator, empty).

## Global Constraints
- Filters show **open** tasks only; sorted by due date (undated last), then priority (high first).
- Saving a filter with an invalid query is blocked in the UI (live validation message).
- Filter names are free text (duplicates allowed, like Todoist).

## Review Focus
- **Operator precedence** (`today | overdue & p1`) and parentheses — Task 1.
- **Dangling/unknown syntax** returns an error rather than matching everything — Task 1.
- **Case-insensitive** project/section/label names — Task 1.
- **Comma groups** keep their own result lists, in order — Task 3.
- **Completed tasks** never appear in filter results — Task 3.
