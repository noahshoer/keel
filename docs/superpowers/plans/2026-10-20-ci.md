# CI: Windows desktop and iOS build checks

**Goal (Noah):** every push checks that Keel builds for Windows (desktop app plus web UI) and for iOS (everything, Swift included). This is verification only: nothing is deployed and nothing is signed.

**Decisions**
- Triggers: every push to any branch, and pull requests into `main`. A newer push to the same branch cancels the older run.
- Runners are free because the repo is public.
- Tool versions match the Mac: `dioxus-cli` 0.7.10 and `tauri-cli` 2.12.3, installed as prebuilt binaries (`taiki-e/install-action`, which uses cargo-binstall).
- Caching: `Swatinem/rust-cache` for the workspace `target/` and `crates/ui/target/` (the UI crate is outside the workspace).

**Jobs**
1. `windows` (windows-latest): `dx build --platform web`, copied to `crates/ui/dist` (first, because `tauri::generate_context!` needs it to compile) → `cargo test` → UI `cargo test` and the wasm `cargo check` → `cargo tauri build --no-bundle` (desktop app, no installer).
2. `ios` (macos-26, default Xcode 26.6): `dx build` → `cargo tauri ios build --target aarch64 --debug --no-sign --ci` (Rust, Swift and the Xcode project, unsigned, iPhone target) → `cargo build --lib -p keel --target aarch64-apple-ios-sim` (simulator, Rust only). The simulator target was tried first: Xcode 26.6 archives it for a device anyway, and the Rust build phase fails with an empty `ARCHS`.

**Not included:** deploying to the phone or TestFlight (that needs the paid Apple Developer Program), Android, macOS desktop.

**Done when:** both jobs pass on GitHub for this branch.
