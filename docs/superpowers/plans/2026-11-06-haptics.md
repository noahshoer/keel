# Haptics: completing a task, long press (2026-11-06)

Asked by Noah: a short two-tone tap when a task is completed (lower first, then
higher, both fast), and one deep thump when a long press registers.

Decisions:
- Screen rule, so it lives in the frontend and Swift: `web/src/shell/haptics.ts`
  sends `haptic { kind }` (`complete` | `press`), never awaited, errors ignored.
- `haptic` is an async Tauri command (it calls into Swift) that forwards to
  `tauri_plugin_keel_ios::haptic`; a no-op off iOS.
- Swift (`Haptics.swift`) plays Core Haptics patterns, where sharpness is the
  "pitch": `complete` is one transient, sharpness 0.5, intensity 0.8 (on the
  phone the two-tone version felt like too much; Noah, 2026-11-06); `press` is
  one transient, sharpness 0.2, full intensity: a pop, not a buzz (Noah,
  2026-11-06, after a 90 ms and then a 40 ms buzz). The engine is made once and restarted after a reset or a stop.
  Devices without Core Haptics fall back to `UIImpactFeedbackGenerator`
  (medium; heavy).
- When: on the tap that starts completing (task row circle, sub-task circle,
  the task view's circle), not when the save lands, so it matches the finger.
  Reopening a task plays nothing. A long press plays when the hold timer fires
  (`long-press.ts`), for tasks, section headers and sidebar rows; a right click
  plays nothing.
