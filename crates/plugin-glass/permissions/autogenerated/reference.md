## Default Permission

Everything the Keel web UI uses

#### This default permission set includes the following:

- `allow-is-available`
- `allow-show`
- `allow-update`
- `allow-hide`
- `allow-buttons`
- `allow-actions`
- `allow-prompt`
- `allow-register-listener`
- `allow-remove-listener`
